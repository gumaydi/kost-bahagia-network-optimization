## Implemented architecture

The finished deployment, as described by the lead, uses an ISP modem and **one Archer AX10 main router** connected to an **Ethernet switch** that distributes to **twelve Archer AX10 AP devices**, four on each of three floors. The team removed early Wi-Fi equipment and standardized on the AX10 model. A common SSID/password and AP-mode implementation support a consistent user experience; the lead reports smooth transitions between zones.

## Project execution and teamwork

Work was completed under **Xiao Systems** leadership, with **Ahmad Ghumaydi as project lead**.
